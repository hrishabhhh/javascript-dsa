## 🎯 Goals

- Strengthen problem-solving skills.
- Understand brute-force and optimized approaches.
- Learn important DSA patterns.
- Analyze time and space complexity.
- Prepare for technical interviews.
- Maintain consistency through regular practice.

## 📌 Approach

For every problem:

1. Understand the problem.
2. Develop a brute-force solution.
3. Optimize the approach.
4. Analyze time and space complexity.
5. Test with different edge cases.
6. Commit the solution to GitHub.
